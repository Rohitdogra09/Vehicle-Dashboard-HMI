#  Vehicle Dashboard HMI

##  Overview
**Vehicle Dashboard HMI** is a Qt/C++-based automotive infotainment system that simulates a modern car dashboard interface. The project integrates essential features like EV battery monitoring, date & time display, phone connectivity, navigation, and media controls into a unified and interactive UI.

>  **Note:** This project is currently under development. New features and improvements are being added continuously.

---

##  Features
-  EV Battery Percentage Display  
-  Real-time Date & Time  
-  Phone Connectivity (UI Simulation)  
-  Navigation / Map Interface  
-  Media Controls (Basic UI)  
-  Interactive Dashboard Design  

---
